# Prompt ideas

Start small. Test in the browser after every change, and commit when it works.

## Make it yours (easy)
- Change the emoji to a theme: space, food truck, Cleveland, your favorite show.
- Change the background colors and the title.
- Make the basket bigger or smaller.

## Add a feature (medium)
- Add a high score that is remembered between visits.
- Add a rare golden item worth 5 points.
- Add a slow-motion power-up that falls sometimes.
- Add sound effects when you catch or miss.
- Add a level system: every 10 points, things fall faster and a new emoji appears.

## Bigger ideas (hard)
- Add a start screen and a pause button.
- Add a second player on the keyboard.
- Turn it into a different game: dodge the falling items instead of catching them.

## Prompting tips
- Say what you want to see, not how to code it: "when I miss a good item, shake the screen".
- Ask for a plan first: "Before you change anything, tell me your plan."
- If it breaks, say what you saw: "the basket stopped moving after I caught a bomb".
- Ask it to explain: "explain what you just changed like I'm new to coding".
