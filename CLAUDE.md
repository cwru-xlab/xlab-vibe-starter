# Emoji Catcher — project rules

This is a beginner-friendly browser game for a workshop. The person you are helping may have never coded.

- Keep everything in a single `index.html`. No build step, no npm, no frameworks, no external files or CDNs.
- It must work by double-clicking the file.
- Explain what you changed in one or two plain sentences. Avoid jargon.
- Make one small change at a time, so it is easy to test and undo.
- Before changing code, say what you plan to do in a sentence or two.
- Never put API keys, tokens, or passwords in any file.
- Do not commit unless asked. When asked, use a short message describing the change.
- Keep the "Easy things to change" block at the top of the script tidy; put new tweakable values there.
